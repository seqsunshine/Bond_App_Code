# Bond  
**A Capstone Android App for Deepening Real-Life Connections**

Bond is an Android application that helps users get to know their friends better. Users can view personalized preferences on individual friend profiles and create "occasions" that consolidate all relevant friend data into a single, useful view.

This project was built as part of the capstone for my Bachelor’s degree in Software Engineering and showcases my skills in full-stack Android development, UI/UX design, local database management, encryption, and modular code organization.

---

## Features:

- **Encrypted Login System**  
  Local login with password encryption.

- **User Dashboard**  
  Displays key actions like editing your profile, managing friends, or creating/viewing occasions.

- **Friend Profiles**  
  Stores personalized data such as preferences, favorite things, dates, and custom fields.

- **Occasions View**  
  Creates an event-style page where all selected friends’ information is compiled for easy reference.

- **Local Persistence with Room Database**  
  Efficient use of SQLite via Room to store user, friend, and occasion data.

- **Custom UI**  
  Built with modular, intuitive interfaces for friend management, date tracking, and profile navigation.

---

## Technologies Used

- Java (Android)
- Android Studio
- Room Database (SQLite)
- RecyclerView for dynamic lists
- Gradle (Kotlin DSL)
- Encrypted SharedPreferences
- Custom adapters and DAOs
